 Reading Tracker
 
A command-line application written in C that helps users manage their personal book collection and track their reading activity.

Overview

Reading Tracker is a project designed to practice and demonstrate core C programming concepts through the development of a practical application.
Users can manage their book collection, start reading sessions, track their progress, and view reading statistics.
Features
Book Management – Add and store books with their titles, authors, and page counts.
Book Library – Display all books in the collection.
Reading Sessions – Start and track reading sessions using a timer.
Reading Statistics – Monitor reading activity and progress.
Input Validation – Handle invalid user input and prevent unexpected behavior.
